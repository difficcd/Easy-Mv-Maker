# Code of conduct

This project takes contributions from anyone, which makes it worth writing down what is
expected. It is short on purpose: the rules that matter here fit on a page.

## What is expected

Be civil about the work. Review a pull request, an issue or a comment on what it does, not on
who wrote it. Assume the other person is trying to make the thing better, because they almost
always are - they are here voluntarily.

Disagreement is fine and useful. "This is wrong because X" is a contribution. "This is stupid"
is not, and neither is the same point repeated more loudly.

English is the language of issues, pull requests, commits and comments, so that everything
stays in one place and one language. Imperfect English is entirely welcome; nobody will be
corrected on grammar.

## What is not

Harassment, personal attacks, discrimination on any ground, sexualised language or imagery,
publishing anyone's private information, and deliberately wasting maintainer time.

## Scope

This applies in the repository - issues, pull requests, discussions, commit messages, code
comments - and anywhere someone is representing the project.

## Reporting

Email the maintainer at owlee1214@gmail.com, or open an issue if it is something that can be
discussed in public. Reports are read by one person, the maintainer, and are not shared.

There is no committee and no appeals process, because there is one maintainer. What happens in
response is a warning, a deleted comment, or a block from the repository, depending on what
occurred. A maintainer who behaved this way would be just as wrong; there is simply nobody
above them to say so, which is worth knowing when you decide whether to report.
