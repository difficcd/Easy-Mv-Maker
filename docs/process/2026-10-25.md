**The one fix without a test was a waiver, not a gap.** `ae290b3`, a fix to a gate script,

finding N3, still open. Corrected below; with it, untested fixes this week were **0**.

The three `strokes` refixes are the first row and the work around it. Each change passed a test

neighbouring case a user reaches first.

**"Pressure doesn't work" was partly not a defect.** The strokes from a PC tablet carried no
pressure at all: Windows Ink off, the tablet seen as a mouse. Reading the saved project before
touching the renderer found it in minutes. The app now says so when it happens (#390).

## Change

1. **N3: the fix measure reads the waiver** (#401). The `No-Test:` rule moved to
   `scripts/commitKind.mjs`, shared by the gate and the metrics. The metrics split *waived* from
   *untested* and count PR titles without a type.
2. **N1: the save path is under the ratchet** (#401). The coverage ratchet holds `server/` to a
   baseline of its own. The backup routes, untested until now, have route tests against a
   temporary data directory. `server/` coverage went from 58.2% to 70.8%.
3. **For render changes, check the neighbouring case.** A practice rather than a gate, because no
   script can name the neighbouring case. Each change touching `src/canvas/` or `src/engine/` gets
   a test of the property a user sees (width along a pressure ramp, which page a preview shows),
   plus one in-app check off the path the change was built for. Every render PR since #392 has
   done this: the pencil v4 PR pinned both old and new strokes, the clip PR tested a copy whose
   part is off the playhead, and the pressure range PR measured the default and a set range.
4. **Read the user's data before the code.** The pressure report was settled by the stored
   points. When a report concerns a saved drawing, the drawing is evidence.
