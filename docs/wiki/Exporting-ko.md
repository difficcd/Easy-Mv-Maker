# 내보내기

나가는 길은 셋이고, 어느 것인지는 메뉴가 아니라 타임라인 바의 배경 설정이 정합니다.

## 영상 (불투명 배경)

상단 바의 **내보내기**. 영화가 초당 30프레임으로 재생되면서 브라우저의 녹화기가 캔버스를
녹화하고, 음원이 있으면 섞습니다. 브라우저가 만들 수 있으면 MP4, 아니면 WebM — 파일 이름이
맞춰집니다.

알아둘 것 둘:

**실시간 녹화입니다.** 녹화 중에 영화가 재생되니 2분짜리는 2분 걸립니다. 화면 주사율에서
샘플링하는 대신 고정된 격자에 프레임을 그려서 — 그게 예전 버전의 끊김을 잡은 것 — 재생보다
빨라질 수는 없습니다.

**비트레이트는 캔버스 크기로 정합니다.** 브라우저에 맡기면 해상도와 상관없이 같은 ~2.5 Mbps를
골라서 1080p 그림이 굶습니다 — 단색 위의 또렷한 선은 굶은 인코더에 최악이라 모서리에 노이즈가
낍니다. 그래서 명시적으로 요청합니다: 1080p30에서 약 7.5 Mbps, 픽셀 수로 비례, 덜 필요한
VP9은 덜. 파일은 예전의 세 배쯤이고 그게 대가입니다.

**그리는 동안 음원을 꺼 두었어도** 내보내기는 녹화 동안 켰다가 다시 끕니다. 소리 끄기는 나를
위한 것이지 영화를 위한 것이 아니고 — 음악 없는 영상에 이유도 안 적혀 있으면 그걸 알게 되는
최악의 방식이니까.

## GIF 또는 PNG 시퀀스 (투명 배경)

타임라인의 배경을 투명으로 바꾸면 **내보내기**가 영상 대신 GIF나 PNG 시퀀스를 내놓습니다.
브라우저는 알파 채널 있는 영상을 녹화하지 못합니다 — 480p쯤 위에서 VP9을 넘기는 하드웨어
인코더에 알파가 없어 프레임이 검정 위로 돌아옵니다 — 그래서 투명 프로젝트는 녹화 대신 한
프레임씩 내보냅니다.

좋은 점도 있습니다: 프레임마다 일부러 그리고, 아직 디코딩 중인 것은 기다리니 빠지거나 겹치는
프레임이 없습니다.

- **GIF** — 파일 하나, 긴 변 720px, 256색. GIF가 원래 그런 것이지 앱의 한계가 아닙니다.
- **PNG 시퀀스** — 원본 크기 무손실 프레임을 번호 붙여 zip으로. 편집 프로그램에서 오버레이로
  쓸 때 원하는 것이고, 무손실로 나가는 유일한 길.

레이어 효과 — 모자이크와 노이즈 — 는 투명 배경에서도 나옵니다. 둘 다 레이어 자체 픽셀에
작용하고 빈 캔버스는 빈 채로 두니 오버레이가 오버레이로 남습니다.

## 여러 조각을 하나로

**파일 → 조각 이어서 내보내기…** — 빠르게 유지하려고 나눈 프로젝트를 위해. 무엇을 하고 왜
메모리가 평평한지는 [컷이 많을 때](Working-with-a-lot-of-cuts-ko).

## 내보내기에 들어가는 것과 아닌 것

- 컷 애니메이션, 파츠 애니메이션, 카메라, 모든 효과는 ▶에서와 정확히 같게 내보내집니다.
  재생에서 맞았으면 내보내기도 맞습니다 — 일부러 같은 그리기 경로를 씁니다.
- 어니언 스킨은 절대 안 나갑니다. 그리기 보조입니다.
- 선택 테두리, 모션 경로 등 편집용 표시는 절대 안 나갑니다.
- 참고 영상 트랙은 *나갑니다*, 설정한 농도 그대로.
